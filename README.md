# GestorTareasEquipo

Gestor de tareas en Java desarrollado en pareja con Git, Eclipse (EGit) y GitHub, usando ramas y pull requests.

## Funcionalidades
- `agregarTarea(String descripcion)`: añade una tarea si el texto no está vacío.
- `listarTareas()`: muestra las tareas numeradas o avisa si no hay ninguna.

## Cómo ejecutarlo
1. En Eclipse: File > Import > Git > Projects from Git > Clone URI.
2. Pega la URL: https://github.com/DiegoRuizHurtado/GestorTareasEquipo.git
3. Abre `src/GestorTareas.java`.
4. Botón derecho > Run As > Java Application.
